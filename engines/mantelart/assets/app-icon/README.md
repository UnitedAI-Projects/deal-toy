# MantelArt icon

An original ivory M path on a coral rounded tile. The circles suggest vector anchors.

The editable source is mantelart.svg; mantelart-small.svg uses the same geometry.
Run bash packaging/icons.sh with resvg, Rust and macOS iconutil to reproduce the PNG, ICO and ICNS exports.

# MantelCAD downloads

MantelCAD is currently distributed as source from [ichen27/mantelcad](https://github.com/ichen27/mantelcad). Repository access is required while it is private. No MantelCAD installer, signed/notarized binary, store listing, or hosted browser app has been published as part of the rebrand.

Use the [README quickstart](../README.md#quickstart) to build the desktop application or CLI. The [build guide](building.md) includes the browser build. Existing packaging scripts are source tools for preparing future packages; inherited upstream release instructions do not establish that MantelCAD packages exist or are signed.

Published MantelCAD packages, if added later, will be listed on the [repository releases page](https://github.com/ichen27/mantelcad/releases) with the source revision, platform, checksums, installation instructions, and signing status. Do not substitute MantelCAD downloads for a MantelCAD build.

Editable examples, artwork, and other repository deliverables are listed in [Artifacts](ARTIFACTS.md).
